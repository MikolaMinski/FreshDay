# Fresh Day — сайт кейтеринга в Минске

Быстрый статический сайт на **Astro 7**: главная, 6 посадочных страниц услуг, галерея, блог, контакты,
калькулятор стоимости и форма заявки с отправкой в Telegram.

| Проверка Lighthouse (мобильный профиль, медленный 4G) | Результат |
| ----------------------------------------------------- | --------- |
| Performance                                           | 91–92     |
| Accessibility                                         | 100       |
| Best Practices                                        | 100       |
| SEO                                                   | 100       |

## Быстрый старт

Нужен **Node.js 22.12+** ([nodejs.org](https://nodejs.org), версия LTS).

```bash
npm install        # один раз — установить зависимости
npm run dev        # локальный сервер: http://localhost:4321
npm run build      # проверка типов + сборка в папку dist/
npm run preview    # посмотреть собранную версию
```

В VS Code: откройте папку проекта → согласитесь установить рекомендуемые расширения →
`Ctrl+Shift+B` запускает сборку, `F5` запускает dev-сервер.

## ⚠️ Перед запуском — заменить заглушки

Все места помечены `TODO` (поиск по проекту: `Ctrl+Shift+F` → `TODO`).

1. **`src/config/site.ts`** — название, домен, телефон, email, Telegram, Viber, Instagram, адрес,
   координаты, УНП, цифры в блоке статистики. Всё остальное подтянется автоматически.
2. **Цены** — поле `priceFrom` в каждом файле `src/content/services/*.md`, ставка официанта в
   `src/data/calculator.ts`. Цены в текстах услуг (жирным) тоже проверьте.
3. **`public/site.webmanifest`** — название для иконки на телефоне.
4. **Политика конфиденциальности** — `src/pages/politika-konfidencialnosti.astro`, согласуйте с юристом.
5. **Логотип** уже подключён (эмблема Fresh Day). Если появится версия в лучшем качестве или в
   векторе — см. раздел «Логотип» ниже.
6. **Отзывы** — добавьте настоящие отзывы в `src/data/reviews.ts`, блок появится сам.

## Как вносить изменения

| Что нужно                        | Где                                                          |
| -------------------------------- | ------------------------------------------------------------ |
| Контакты, название, меню сайта   | `src/config/site.ts`                                         |
| Текст, цены, FAQ услуги          | `src/content/services/<услуга>.md`                           |
| Новая услуга                     | скопируйте любой `.md` в `src/content/services/` и измените  |
| Новая статья в блог              | новый `.md` в `src/content/blog/`                            |
| Фото в галерею                   | файл в `src/assets/photos/` + строка в `src/data/gallery.ts` |
| Общие вопросы на главной         | `src/data/faq.ts`                                            |
| Преимущества, шаги, типы событий | `src/data/content.ts`                                        |
| Цвета, шрифты, отступы           | переменные в начале `src/styles/global.css`                  |
| Логотип                          | `src/assets/brand/logo-emblem.png` (см. ниже)                |

**Имена файлов** — латиницей через дефис: имя `.md`-файла становится адресом страницы
(`svadba.md` → `/uslugi/svadba/`).

**Фото** можно класть как есть (JPG с телефона): при сборке они автоматически сжимаются и
нарезаются в AVIF/WebP под разные экраны. Перед загрузкой удалите лица гостей и чужие логотипы,
если нет разрешения на публикацию.

**Проверка полей.** Если в `.md` забыть обязательное поле, ошибиться в пути к фото или сделать
`description` слишком длинным, `npm run build` остановится и покажет понятную ошибку — сломанная
страница на сайт не попадёт.

## Логотип

Эмблема вырезана из присланного `LOGO.jpg` (салатовый фон удалён) и используется в нескольких
местах:

| Файл                                                          | Для чего                                                |
| ------------------------------------------------------------- | ------------------------------------------------------- |
| `src/assets/brand/logo-emblem.png`                            | логотип в шапке и подвале (сайт сам сжимает его в WebP) |
| `public/logo.png`                                             | логотип для Яндекса/Google (микроразметка организации)  |
| `public/favicon.ico`, `favicon-96.png`                        | значок во вкладке браузера                              |
| `public/apple-touch-icon.png`, `icon-192.png`, `icon-512.png` | значок на экране телефона                               |
| `public/og-image.jpg`                                         | картинка при отправке ссылки в Telegram/Viber/соцсети   |

Исходник был 1024×559 px, поэтому эмблема получилась около 400×400 px — для сайта достаточно.
Если у дизайнера есть логотип в векторе (SVG/AI/PDF) или PNG с прозрачным фоном от 1000 px —
замените файлы выше, это сделает значки чётче. Цвета сайта подобраны под логотип: салатовый
акцент и глубокий зелёный (`--c-accent` и `--c-primary` в `src/styles/global.css`).

## Форма заявки

Заявки отправляет `public/api/lead.php` (PHP 8+, есть на любом виртуальном хостинге в Беларуси).

1. Создайте бота в Telegram через [@BotFather](https://t.me/BotFather), сохраните токен.
2. Напишите боту любое сообщение, откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите
   `"chat":{"id": ...}` — это ваш `chat_id`. Для группы — добавьте бота в группу.
3. Скопируйте `public/api/config.example.php` → `public/api/config.php` и впишите токен и `chat_id`
   (можно несколько — заявка придёт всем). По желанию укажите email.

Каждая заявка также сохраняется в `api/leads.log` на хостинге (закрыт от просмотра извне) — на
случай, если Telegram недоступен.

Защита от спама: скрытое поле-ловушка, проверка данных на сервере, ограничение частоты отправки.
Без JavaScript форма тоже работает — после отправки открывается страница `/spasibo/`.

> Если сайт будет на хостинге без PHP (Netlify, Vercel, Cloudflare Pages), поменяйте
> `formEndpoint` в `src/config/site.ts` на адрес сервиса форм (Formspree, Web3Forms и т.п.).

## Публикация на GitHub Pages (бесплатно)

В проекте уже есть автодеплой: `.github/workflows/deploy.yml`. После настройки каждый `git push`
в ветку `main` сам собирает и публикует сайт примерно за 2 минуты.

1. Создайте на GitHub новый репозиторий (например, `catering-minsk`). Он должен быть **публичным**
   (на бесплатном тарифе GitHub Pages работает только с публичными).
2. Отправьте проект в репозиторий (в терминале VS Code, из папки проекта):
   ```bash
   git remote add origin https://github.com/<ваш-логин>/catering-minsk.git
   git push -u origin main
   ```
   Или в VS Code: вкладка **Source Control** → **Publish Branch**.
3. На GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Откройте вкладку **Actions**. Если сборка упала (первый запуск иногда стартует раньше шага 3),
   нажмите **Re-run all jobs**. Когда станет зелёной, сайт откроется по адресу
   `https://<ваш-логин>.github.io/catering-minsk/`.

Адрес и префикс `/catering-minsk/` в ссылках подставляются автоматически, код менять не нужно.
Внутренние ссылки в `.astro`-файлах пишите через `url('/путь/')` из `src/lib/url.ts`, а в статьях —
относительными (`../../galereya/`), тогда они работают и с префиксом, и без.

### Свой домен (например, freshday.by)

1. **Settings → Pages → Custom domain** → впишите `freshday.by` → Save.
2. У регистратора домена создайте DNS-записи (GitHub покажет их в той же настройке):
   четыре `A`-записи для `freshday.by` → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`,
   `185.199.111.153` и `CNAME` для `www` → `<ваш-логин>.github.io`.
3. **Settings → Secrets and variables → Actions → Variables → New repository variable**:
   `CUSTOM_DOMAIN` = `freshday.by`. Перезапустите деплой: вкладка **Actions** → **Run workflow**.
4. Когда сертификат выпустится (от нескольких минут до суток), включите **Enforce HTTPS**.

### Форма заявки на GitHub Pages

GitHub Pages отдаёт только статические файлы: PHP там не работает, поэтому `lead.php` не
сработает. Используйте бесплатный [Web3Forms](https://web3forms.com): укажите email, получите
Access Key и добавьте его переменной репозитория `PUBLIC_WEB3FORMS_KEY` (там же, где
`CUSTOM_DOMAIN`). Затем перезапустите деплой, и заявки начнут приходить на почту. Ключ
публичный по задумке сервиса, его можно хранить в переменных, а не в секретах.

Так же через переменные задаются `PUBLIC_YANDEX_METRIKA_ID`, `PUBLIC_GA_ID`,
`PUBLIC_YANDEX_VERIFICATION` и `PUBLIC_GOOGLE_VERIFICATION`.

## Публикация на обычном хостинге

**Обычный хостинг (hoster.by, active.by и др.):**

1. `npm run build`
2. Загрузите **содержимое** папки `dist/` в корень сайта (`public_html` / `www`) по FTP/SFTP.
3. Создайте на хостинге `api/config.php` (шаг 3 из раздела «Форма заявки»).
4. Подключите SSL-сертификат (Let's Encrypt обычно бесплатно в панели хостинга).

`.htaccess` уже настроен: HTTPS, редирект с www, сжатие, кеширование, страница 404.

**Счётчики аналитики:** скопируйте `.env.example` → `.env`, впишите номер Яндекс Метрики и/или
Google Analytics и коды подтверждения вебмастеров, пересоберите сайт. В Метрике создайте цель
«JavaScript-событие» с идентификатором `lead` — она срабатывает при отправке заявки.

## SEO: что уже сделано

- Название указано в двух написаниях — «Fresh Day» и «Фреш Дэй» (`alternateName`), чтобы
  компанию находили при поиске кириллицей.

- Отдельная посадочная страница под каждый запрос: «фуршет Минск», «банкет Минск», «кофе-брейк
  Минск», «кейтеринг на свадьбу», «кейтеринг на корпоратив», «выездной кейтеринг».
- Уникальные `title` и `description`, один `H1` на странице, ЧПУ-адреса латиницей, `canonical`.
- Микроразметка Schema.org: `LocalBusiness` (адрес, телефон, часы, зона обслуживания), `Service`
  с ценами, `FAQPage`, `BreadcrumbList`, `BlogPosting` — для расширенных сниппетов в Яндексе и Google.
- `sitemap-index.xml`, `robots.txt`, Open Graph-картинки для мессенджеров и соцсетей.
- Упоминание районов Минска и населённых пунктов Минского района — для локальной выдачи.
- Скорость: статический HTML, 0 фреймворков в браузере, ~5 КБ JS, современные форматы картинок,
  предзагрузка шрифтов, отложенная загрузка карты.
- Доступность: семантическая разметка, контраст AA, работа с клавиатуры, `prefers-reduced-motion`.

## SEO: что сделать после запуска (важнее, чем код)

Для запроса «кейтеринг минск» в топе решают не только страницы, но и доверие к компании:

1. **Яндекс Вебмастер** и **Google Search Console** — добавить сайт, отправить `sitemap-index.xml`.
2. **Яндекс Бизнес** (карточка в Картах) и **Google Business Profile** — с тем же адресом,
   телефоном и названием, что на сайте. Это даёт место в блоке карт в выдаче.
3. Каталоги: 2ГИС, relax.by, ta-da.by, свадебные каталоги — везде одинаковые контакты (NAP).
4. **Отзывы** на Яндекс Картах и Google — просите у каждого довольного клиента.
5. **Регулярный контент**: 1–2 статьи в месяц (`src/content/blog/`) под вопросы клиентов —
   «меню на юбилей», «кейтеринг на выпускной», «сколько стоит свадьба на 50 гостей».
6. Новые фото с каждого мероприятия в галерею — с понятным `alt`.
7. Посадочные страницы под новые направления по мере роста: «кейтеринг на выпускной»,
   «поминальные обеды», «барбекю-кейтеринг» — копия `.md` с новым текстом.

## Технологии и архитектура

- **Astro 7** — статическая генерация, компонентный подход, ноль JS по умолчанию.
- **Content Collections + Zod** — контент в Markdown с проверкой схемы при сборке.
- **astro:assets + sharp** — автоматическая оптимизация изображений (AVIF/WebP, `srcset`).
- **Современный CSS без фреймворков**: дизайн-токены, `oklch`, `clamp()`, container queries,
  View Transitions между страницами, Popover API для мобильного меню, `<dialog>` для лайтбокса,
  анимируемые `<details>`.
- **TypeScript strict**, Prettier, EditorConfig, настройки и задачи VS Code.

```
src/
├── config/site.ts        ← главные настройки: контакты, название, домен
├── content/

public/

└── .htaccess             ← настройки Apache
```
